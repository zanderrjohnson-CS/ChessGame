How it works

Each move, the engine searches several moves ahead with alpha-beta pruning and quiescence search, then scores positions with piece-square tables plus 29 features such as passed pawns, rooks on open files, king safety and mobility. The feature weights were learned from 725,000 labeled positions with logistic regression (Texel tuning). Source on GitHub.
